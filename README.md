# sait
Sait Mods
Учебный проект по веб-разроботке за 3 курс. Это сайт для модов (что-то вроде Nexus Mods, но проще). Главная задача была связать Python (Flask) с базой данных Microsoft Access и сделать рабочий сайт.

Технологии
Python 3 (Flask)

База данных: Microsoft Access (файл dt.accdb)

Драйвер для базы: pyodbc

Верстка: HTML, CSS, шаблонизатор Jinja2

Что умеет сайт
Каталог модов с обложками, фильтрами по играм и категориям, а также поиском.

Страница мода с описанием, счетчиком скачиваний и ссылками на файлы.

Регистрация и вход пользователей.

Личный кабинет, где можно посмотреть свои загруженные моды.

Форма загрузки нового мода (с возможностью загрузить картинку).

Отзывы с оценками на странице мода.

Как запустить
Для работы нужен Windows (потому что используется Access) и установленный Python.

Скачать репозиторий:
git clone https://github.com/overrsyy-web/sait.git
cd sait

Установить нужные библиотеки:
pip install flask python-dotenv pyodbc werkzeug

Создать в корневой папке файл .env и написать там одну строку:
SECRET_KEY=любая_случайная_строка
(Это нужно для работы сессий Flask, в гит этот файл не загружается из соображений безопасности).

Запустить сервер:
python server.py

Открыть в браузере ссылку, которую напишет программа в консоли (обычно http://127.0.0.1:3000).

Известные проблемы и ограничения
Access очень плохо работает с русскими буквами через Python. Иногда он путает названия колонок или ломается на сложных запросах, поэтому в коде есть несколько костылей (например, функция get_val в server.py), чтобы это обойти.
Пароли в базе хранятся в открытом виде. Так было нужно по заданию, но для реального сайта это, конечно, небезопасно.
Сами файлы модов не загружаются на сервер (чтобы не забивать диск). В базу записывается только ссылка на скачивание. На сервер загружаются только картинки-обложки.

Что можно сделать лучше
Перейти на нормальную базу данных (SQLite или PostgreSQL), потому что с Access слишком много проблем.
Сделать хеширование паролей.
Сделать загрузку файлов на сервер напрямую.
